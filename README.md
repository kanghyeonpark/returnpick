## 4. 링크·상품 교체 방법

`data.js`의 `RETURNPICK_DEALS` 배열에서 항목 하나가 카드 하나입니다.

```js
{
  id: "purus-humidifier",
  category: "appliance",          // appliance | living | food | fashion  (상단 필터와 연결)
  categoryPath: "헬스/건강식품 › 호흡/수면건강 › 가습기/에어워셔",
  name: "풀라스 복합식 가습기 7L",
  sub: "100도 가열 살균 · 무소음 · 자동 습도조절",
  grade: "반품-최상",              // 박스 훼손 | 반품-최상 | 반품-상 | 반품-중
  original: 299990,               // 정가(새 상품 기준가)
  price: 125800,                  // 반품 특가
  discount: 58,                   // 할인율 %
  stock: 4,                       // 남은 수량 (모르면 null → 배지 숨김)
  condition: "개봉됨 · 사용감 없음 · 구성품 모두 포함",
  image: "images/purus-humidifier.jpg",
  url: "https://www.coupang.com/vp/products/...&landingType=USED_DETAIL",
  partnerUrl: "https://link.coupang.com/a/iUiqMyRNqC"   // 없으면 null
}
```

- `discount`를 비우면 통계·점수에 반영되지 않으니 함께 채워 주세요.
- 새 상품을 추가하면 `window.RETURNPICK_META.collectedAt`(수집 시각)도 같이 갱신하면 하단 안내 문구가 자동으로 바뀝니다.
- 새 카테고리를 만들려면 `META.categories`에 `{ key, label }`을 추가하고 상품의 `category`를 맞추면 탭과 개수가 자동 생성됩니다.
- 이미지는 `images/` 폴더에 저장하고 상대 경로로 넣으면 외부 CDN이 막혀도 깨지지 않습니다.
